المشكلة الأصلية:
واتساب (نسخة قديمة) على iOS قديم بيرفض يشتغل.
بيظهر شاشة "حدث نسختك" أو "نظامك قديم" وكمان السيرفر بيرفض الاتصال
لأنه بيشوف إن نسخة iOS / نسخة التطبيق قديمة.

ايه اللي عملناه:
أول حاجة استخدمنا Frida عشان نفهم المشكلة ونجرب الحلول.
لقينا إن واتساب بيعمل كذا check:

1. بيشيك على نسخة البيلد (WABuildVersion) - لو قديمة بيقولك حدث
2. بيشيك هل نظامك أقدم من الحد الأدنى (WAIsAfterDeprecatedPlatformCutoffDate)
3. بيبعت نسخة iOS في الـ User-Agent للسيرفر - السيرفر بيرفض iOS القديم
4. بيبعت نسخة التطبيق في بروتوكول protobuf - السيرفر بيشيكها
5. لو في تناقض بين النسخ بيعمل crash عن طريق WAHandleFailureInFunction

الحل:
عملنا dylib (مكتبة ديناميكية) بتتحقن في واتساب وقت التشغيل
وبتعترض الـ functions دي وبترجع قيم مزيفة.

دي أهم حاجة تقرأها لو البيلد فشل على GitHub Actions.


--- مشكلة 1: _mprotect و _sys_icache_invalidate مش موجودين ---

الخطأ:
  ld: symbol(s) not found for architecture arm64
  Undefined symbol: _mprotect
  Undefined symbol: _sys_icache_invalidate

السبب:
  الـ WASendFix.c بيستخدم mprotect() و sys_icache_invalidate()
  عشان يعمل ARM64 body patching (تغيير bytes في الذاكرة مباشرة).
  الـ stub file بتاعة libSystem.B.tbd مكانتش بتعلن عن الـ symbols دي.

الحل:
  افتح: stubs/usr/lib/libSystem.B.tbd
  وأضيف تحت قسم symbols:
      - _mprotect
      - _sys_icache_invalidate


--- مشكلة 2: ld: unknown file type in libSystem.B.tbd ---

الخطأ:
  ld: unknown file type in stubs/usr/lib/libSystem.B.tbd

السبب:
  ملف TBD (Text-Based stub Definition) لازم ينتهي بـ ... (ثلاث نقاط)
  وهو YAML end-of-document marker. لو الملف ناقصه في الآخر،
  الـ Apple ld بيرفضه كـ "unknown file type".

الحل:
  تأكد إن آخر سطر في stubs/usr/lib/libSystem.B.tbd هو:
  ...
  (ثلاث نقاط بدون مسافات قبلها أو بعدها)

  الملف الصح يبدأ بـ --- وينتهي بـ ...


--- مشكلة 3: macos-latest = macOS 26 (Xcode 26) ---

الخطأ:
  ld: unknown file type in stubs/usr/lib/libSystem.B.tbd
  (نفس الخطأ فوق بس السبب مختلف!)

السبب:
  GitHub Actions غيّر macos-latest لـ macOS 26 مع Xcode 26.
  الـ Apple ld في Xcode 26 بيرفض صيغة TBD version 4 القديمة
  حتى لو الملف مكتوب صح!

الحل:
  في .github/workflows/build.yml غيّر:
    runs-on: macos-latest
  لـ:
    runs-on: macos-14

  macOS 14 فيه Xcode 15 اللي بيدعم TBD v4 عادي.

  ملاحظة مهمة للمستقبل:
  لو macos-14 بقى قديم جداً ومش متاح، جرب macos-15.
  الهدف هو Xcode 15 أو 16 مش 26+.
  لو اضطريت تستخدم macos-latest، حل بديل هو:
    brew install llvm
    export PATH="$(brew --prefix llvm)/bin:$PATH"
  (بس ده بياخد وقت طويل في الـ CI)


--- مشكلة 4: clang sysroot warning ---

التحذير:
  clang: warning: using sysroot for MacOSX but targeting iPhone

السبب:
  GitHub Actions مش فيه iOS SDK، فـ clang بيستخدم macOS SDK
  كبديل. ده warning بس مش error، البيلد بيكمل عادي.
  ما تقلقش منه.
